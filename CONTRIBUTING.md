# Contributing to AttendX

Thanks for contributing to AttendX.

## Project areas
- Student attendance and dashboard experience
- Professor dashboard, attendance, students, and reports
- Authentication and Supabase integration
- Responsive UI and accessibility

## Workflow
1. Create a focused branch from `master`.
2. Make a small, purposeful change.
3. Run the available lint/build checks before opening a pull request.
4. Describe what changed and how it was tested.

## Pull requests
Keep pull requests focused, explain the user-facing impact, and avoid unrelated changes.
