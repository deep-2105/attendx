# AttendX

A modern attendance management web application built with React and Vite.

## Overview
AttendX is designed to simplify attendance workflows with a responsive interface and application features for managing attendance-related information.

## Highlights
- Attendance management workflow
- Responsive UI
- Authentication and user flows
- Supabase-backed application features
- Production-ready frontend structure

## Tech Stack
React · Vite · JavaScript · Supabase

## Development
```bash
npm install
npm run dev
```

## Purpose
A practical full-stack web project demonstrating modern frontend development, authentication, database integration, and responsive UI design.
