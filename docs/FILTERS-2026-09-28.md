# AttendX Filtering Guidance — September 28, 2026

Filters should make attendance and reporting views easier to inspect without changing the underlying records.

Filtering should:

- clearly identify the selected criteria;
- update the visible result set predictably;
- preserve role-based access boundaries; and
- avoid treating filtered results as a replacement for the underlying database records.

When filters are combined, the resulting state should remain understandable to the user.
