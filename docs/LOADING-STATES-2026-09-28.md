# AttendX Loading States — September 28, 2026

Loading states should clearly communicate when AttendX is resolving authentication, profiles or application data.

A loading state should not be presented as a successful result or as a genuine authorization failure.

Important areas include:

- authentication/session restoration;
- profile and role resolution;
- attendance data loading; and
- report or analytics data loading.

Loading indicators should preserve the surrounding application's navigation and visual hierarchy.
