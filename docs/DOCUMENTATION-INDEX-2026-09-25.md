# AttendX Documentation Index — September 25, 2026

The AttendX repository includes supporting documentation for the application's development and maintenance.

## Main Areas

- **Architecture:** application layers, authentication and role boundaries.
- **Testing:** regression checks for authentication, portals, attendance and responsive UI.
- **Security:** credential handling, Row Level Security and authorization principles.
- **Development:** local setup, branch workflow and commit practices.
- **Deployment:** production configuration and smoke testing.
- **Accessibility:** navigation, contrast, forms and responsive behavior.
- **Troubleshooting:** common build, authentication, navigation and deployment issues.
- **Data model:** attendance record and reporting concepts.

Documentation is intended to complement the working application without replacing its source code or database configuration.
