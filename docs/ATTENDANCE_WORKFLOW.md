# AttendX Attendance Workflow

This document records the intended attendance workflow used while refining AttendX.

## Student workflow

1. Review the current attendance percentage for each subject.
2. Identify subjects that are close to a shortage threshold.
3. Use the available attendance data to understand required future attendance.
4. Recheck the dashboard after attendance records change.

## Refinement checklist

- Keep attendance percentages easy to scan.
- Make shortage or warning states understandable without relying only on color.
- Keep calculations consistent between dashboard views.
- Test important flows at mobile and desktop widths.
- Avoid exposing sensitive student information in public UI or documentation.

This document is intentionally focused on product behavior and refinement rather than implementation-specific credentials or private configuration.
