# AttendX Accessibility Guidelines

## Navigation

- Keep navigation labels descriptive.
- Provide a visible active state.
- Keep keyboard focus visible.
- Ensure navigation controls remain usable at smaller widths.

## Controls

Buttons should have clear labels and sufficient clickable area. Icon-only controls should provide an accessible name when used.

## Contrast

Text must remain readable against its background. Active, hover, disabled and error states should remain distinguishable rather than relying only on color.

## Forms

Login and attendance forms should provide clear labels, validation feedback and understandable error messages.

## Tables and Charts

Important information should not depend solely on color. Tables should remain readable on narrow screens, while charts should be accompanied by understandable labels or summaries where appropriate.

## Loading and Error States

Users should be able to understand whether data is loading, unavailable or successfully loaded. Protected pages should not display a misleading authorization error while authentication or role resolution is still in progress.

## Responsive Design

The interface should be reviewed at desktop, tablet and mobile widths. Content should remain accessible without requiring unnecessary horizontal scrolling.
