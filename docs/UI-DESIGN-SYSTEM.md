# AttendX UI Design System

## Visual Direction

AttendX uses a professional academic SaaS visual language with dark navy foundations and restrained violet/blue accents.

## Layout

Pages should maintain consistent spacing, readable content widths and clear visual hierarchy. Dashboard sections should distinguish primary metrics from secondary information.

## Navigation

Professor and student navigation are intentionally different because their responsibilities differ. Active, hover and focus states should remain clearly visible.

## Components

Common interface patterns include:

- KPI cards
- Tables
- Forms
- Navigation items
- Buttons
- Status indicators
- Charts and analytics cards
- Empty and loading states

Components should remain visually consistent rather than introducing unrelated styles for individual pages.

## Accessibility

Text contrast, keyboard focus, readable labels and sufficiently large interaction areas are part of the design system.

## Responsive Behavior

Large dashboards should adapt to tablet and mobile widths. Tables, charts and navigation must remain usable without depending on a desktop-only layout.

## Design Principle

Visual polish should improve clarity and usability. Effects, gradients and decorative elements should remain secondary to the actual attendance workflow.
