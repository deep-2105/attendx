# AttendX User Flow — September 27, 2026

## Public Flow

1. Open AttendX.
2. Choose the appropriate role.
3. Continue to the professor or student login screen.
4. Authenticate with Supabase.

## Professor Flow

After successful authentication, the professor profile is resolved and the professor portal provides dashboard, students, attendance, reports, analytics and settings.

## Student Flow

After successful authentication, the student profile is resolved and the student portal provides dashboard, subjects, attendance, analytics and profile.

## Logout

Logout clears the authenticated application state and returns the user to the public flow.

## Security Boundary

The visible navigation is a user-experience layer. Protected database access must continue to be enforced by backend authorization and Row Level Security.
